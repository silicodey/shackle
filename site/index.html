Read this before you install

Shackle is new. We would rather tell you its limits than have you find them.

  • Whoever you let in has full control. They see your screen and can open your files, your email and your banking. Scammers use remote-control tools of every brand to steal money. Never give your ID and password to someone who contacted you first, whatever they say they are from.
  • The installers are not code-signed. Windows shows "unknown publisher" and macOS blocks the first launch. That also means your computer cannot confirm the download came from us. Download only from this page and compare the file with the published checksums if you can.
  • No independent security audit yet. The code has been reviewed and tested by its authors only. It is open source so anyone can inspect it.
  • The connection server sees who connects to whom. Screen, keyboard and files travel encrypted between the two computers and are not readable by the server. The server does see IP addresses, IDs and connection times.
  • A compromised server could attack the password check. If someone took over the server and intercepted a connection attempt, they could try to guess that session's password offline. Passwords are random and change after every session, which limits this, but it is not yet mathematically ruled out.
  • Files you receive are not scanned. Treat a file sent through Shackle like any download.
  • This is an early preview on a small free server. The first connection can take a minute, and on some mobile or company networks it will not connect at all.

What we do to reduce misuse: you approve every connection on screen, after the caller has already proven they know your password. A banner showing who is connected stays on top for the whole session. Passwords are single use. Settings that would let someone back in later are locked while anyone is connected. The app always shows its icon in the system tray while it is running. Three ways to connect

Help someone, or reach your own machines

App to app

Both people install Shackle. Type the other computer's ID, then its password. The other person clicks Allow. No account needed.

Unattended access

Install the host on your own computer, sign it in to your account once and set an access password. It appears under "Your computers" in the web client whenever it is on.

Support session

The other person reads you their 9-digit ID and one-time password and gets an Allow or Decline prompt. The ID and password change after every session.

How it works

The server introduces.
The computers talk.

The Shackle server only sets up the connection. Screen, keyboard and files then travel directly between the two computers over encrypted WebRTC, through your own relay only when a direct path is impossible.

Get started

Connected in three steps

  1. 1

    Both install Shackle

    Open it. Each computer gets its own ID and a one-time password.

  2. 2

    Share ID and password

    The person being helped reads theirs out. The helper types them in.

  3. 3

    Click Allow

    Nothing happens until the person at the computer approves. They can end it at any moment.

Self-host

Run your own server

One Docker Compose file brings up the Shackle server, automatic HTTPS and a TURN relay for strict networks. Then reach your computers from any browser.

Server setup guide →

~/shackle
# fill in DOMAIN, PUBLIC_IP, TURN_SECRET
$ cp .env.example .env
$ docker compose up -d
$ docker compose logs shackle
# shows the one-time setup code
