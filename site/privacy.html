Privacy policy

Last updated: 15 November 2026

Shackle is free, open-source remote desktop software made by Silicode. This policy covers the Shackle apps for Windows, Mac and Android, the connection server at shackle.onrender.com, and this website.

What we never see

Your screen, keyboard and mouse input, clipboard and transferred files travel encrypted directly between the two devices in a session. They do not pass through our server in readable form, and we do not record them.

What the connection server processes

  • Connection details: the IP addresses of both devices, the temporary 9-digit ID, and when a session starts and ends. These are needed to introduce the two devices to each other and to limit abuse. They are kept in memory and in short-lived server logs, and are not sold or shared.
  • Accounts (optional): if you create an account for unattended access, we store your email address, a hashed password, the names of your enrolled computers and a short activity log. On the free public server this data is erased whenever the server restarts.
  • A session cookie if you sign in, used only to keep you signed in.

The apps contain no advertising, analytics or tracking.

The Android app

The Android app shows the server's connect page. It asks for no device permissions and reads no contacts, photos, location or files. A file is sent only when you choose one yourself during a session.

This website

This page counts visits with Google Analytics only if you click Allow on the banner. If you allow it, Google sets cookies and receives your IP address and browser details. You can change your choice at any time with the link at the bottom of the home page.

Other services involved

The server is hosted by Render, this website by Cloudflare, and downloads by GitHub. Each processes your IP address when you use it. Sessions use Google's public STUN servers to find a direct path between devices, which shows them your IP address.

Your choices

You can use Shackle without an account. To have account data removed, or to ask anything about this policy, contact Silicode through silicode.co. You can also run your own server, in which case none of this data reaches us; the source code is on GitHub.

Changes

If this policy changes, the new version is published on this page with a new date.
